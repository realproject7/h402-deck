#H402 팀

x402 payment rail — 그리고 x402가 시작한 Agentic Commerce 트렌드 — 를 GIWA로 가져오는 팀입니다. 에이전트 capability를 위한 x402 라우터 h402를 만들고, 2018년부터 제품을 출시해온 온체인 Builder & Agent Economy 프로덕트 스튜디오 Hunt Town을 운영합니다. 이 문서는 우리가 누구인지, 무엇을 만들어왔는지, 왜 GASOK에 적합한 팀인지에 답합니다.

##핵심 강점

Agentic Commerce를 GIWA로 가져올 수 있는 실전 팀

x402는 HTTP 402를 에이전트 네이티브 결제 표준으로 만들었고, 우리는 이미 프로덕션에서 그 위에 빌드하고 있습니다. h402는 x402 핸드셰이크 전체(402 견적 → 로컬 EIP-3009 서명 → facilitator 정산, 논커스터디얼, API 키 없음)를 구현했습니다. 이 레일을 GIWA로 포팅하고 GIWA의 x402 facilitator를 직접 구축·운영하는 것은 이 팀에게 리서치가 아니라 실행 과제입니다.

##GIWA에서 만들 것

두 가지 딜리버러블입니다. (1) h402가 GIWA를 정산 체인으로 추가 — 카탈로그의 모든 capability가 GIWA 위 스테이블코인으로 호출당 결제됩니다. (2) GIWA x402 facilitator를 직접 구축·운영 — 서명된 결제 페이로드를 검증하고 온체인에 정산하는 서비스로, GIWA 위 어떤 판매자든 노드 운영 없이 에이전트 결제를 받을 수 있게 됩니다. GIWA의 1초 블록과 낮은 수수료는 에이전트 마이크로페이먼트에 정확히 맞는 환경입니다.

에이전트는 라우터 호출 한 번 — 견적·서명·온체인 정산은 아래 레이어가 자동 처리합니다.

##Core strengths

The team that can actually bring Agentic Commerce to GIWA

x402 turned HTTP 402 into a live, agent-native payment standard — and we already build on it in production. h402 implements the full x402 handshake (402 quote → local EIP-3009 signing → facilitator settlement, non-custodial, no API keys). Porting this rail to GIWA — including operating GIWA's x402 facilitator — is an execution task for this team, not research.

A product-level router, waiting for a rail — a new market for GIWA

h402 is already built to product level and in final testing (official launch expected in ~2–3 weeks): 152 capabilities across 74 providers on the live catalog, every route verified with real paid calls, best-provider routing by live quality-adjusted price. Once the payment rail lands on GIWA, hundreds-to-thousands of agent-callable APIs form a new pay-per-call market settling on GIWA from day one — transaction volume, not promises.

##What we're building on GIWA

Two deliverables: (1) h402 adds GIWA as a settlement chain — every capability in the catalog becomes payable in stablecoins on GIWA, per call; (2) we build and operate the GIWA x402 facilitator — the service that verifies signed payment payloads and settles them onchain, so any seller on GIWA can accept agent payments without touching a node. GIWA's 1-second blocks and low fees are exactly the environment agent micropayments need.

One router call for the agent — quote, signature, and onchain settlement handled underneath.
