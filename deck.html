03How it works

x402: HTTP 402를 에이전트 결제 표준으로

STEP 1
에이전트가 능력 호출
평범한 HTTP 요청.
키·토큰 없음.
POST /routes/web/search
→
STEP 2
서버가 서명된 견적 응답
금액·수취인·만료가 담긴
결제 요구.
402 Payment Required
→
STEP 3
로컬 키로 서명
EIP-3009 서명. 키는 기기 밖으로
나가지 않음. 논커스터디얼.
transferWithAuthorization
→
STEP 4
facilitator가 온체인 정산
서명 검증 → 체인 정산 → 결과 반환.
가스는 facilitator가 대납.
✓ 200 OK · settled
논커스터디얼 API 키 없음 이중과금 방지 (idempotency) 무료 라우트는 즉시 응답
