##Core strengths

The team that can actually bring Agentic Commerce to GIWA

x402 turned HTTP 402 into a live, agent-native payment standard, and we already build on it in production. h402 implements the full x402 handshake (402 quote → local EIP-3009 signing → facilitator settlement, non-custodial, no API keys). Porting this rail to GIWA, including operating GIWA's x402 facilitator, is an execution task for this team, not research.

h402 is already built to product level and in final testing, with the official launch expected in 2-3 weeks: 152 capabilities across 74 providers on the live catalog, every route verified with real paid calls, best-provider routing by live quality-adjusted price. ##What we're building on GIWA

Two deliverables. (1) h402 adds GIWA as a settlement chain, so every capability in the catalog becomes payable in stablecoins on GIWA, per call. (2) We build and operate the GIWA x402 facilitator: the service that verifies signed payment payloads and settles them onchain, so any seller on GIWA can accept agent payments without touching a node. GIWA's 1-second blocks and low fees are exactly the environment agent micropayments need.

One router call for the agent. Quote, signature, and onchain settlement are handled underneath.

#h402 팀 소개

x402 payment rail, 그리고 x402가 촉발한 Agentic Commerce 흐름을 GIWA로 가져오려는 팀입니다. 저희는 에이전트 capability를 위한 x402 라우터 h402를 만들고 있고, 2018년부터 온체인 제품을 만들어온 프로덕트 스튜디오 Hunt Town을 운영하고 있습니다. 이 문서에는 저희가 어떤 팀인지, 지금까지 무엇을 만들어왔는지, 왜 GASOK에 맞는 팀인지를 담았습니다.

##핵심 강점

Agentic Commerce를 GIWA에 가장 잘 이식할 수 있는 팀

x402는 HTTP 402를 에이전트를 위한 결제 표준으로 만들었고, 저희는 이미 그 위에서 프로덕션 제품을 만들고 있습니다. h402는 402 견적, 로컬 EIP-3009 서명, facilitator 정산으로 이어지는 x402 핸드셰이크 전 과정을 구현했습니다. API 키도, 커스터디도 없습니다. 이 레일을 GIWA로 옮기고 GIWA의 x402 facilitator를 직접 구축해 운영하는 일은 저희에게 연구 과제가 아니라 실행의 문제입니다.

제품은 이미 완성 단계, 남은 것은 레일. GIWA에 새 시장이 열립니다

h402는 이미 제품 레벨로 완성되어 마지막 테스트를 진행 중이며, 정식 런칭까지 약 2~3주 남았습니다. 라이브 카탈로그에는 152개 capability와 74개 provider가 올라와 있고, 모든 라우트는 실제 결제 호출로 검증을 마쳤습니다. GIWA에 payment rail이 연결되는 순간 수백에서 수천 개의 에이전트 호출형 API가 GIWA 위에서 pay-per-call로 정산되는 시장이 첫날부터 열립니다. 약속이 아니라 트랜잭션으로 증명하겠습니다.

##GIWA에서 만들 것

저희가 GIWA에서 만들 것은 두 가지입니다. 첫째, h402에 GIWA를 정산 체인으로 추가합니다. 카탈로그의 모든 capability가 GIWA 위에서 스테이블코인으로, 호출 단위로 결제됩니다. 둘째, GIWA x402 facilitator를 직접 구축하고 운영합니다. 서명된 결제 페이로드를 검증해 온체인에 정산하는 서비스로, GIWA 위의 어떤 판매자든 노드 운영 없이 에이전트 결제를 받을 수 있게 됩니다. 1초 블록과 낮은 수수료를 갖춘 GIWA는 에이전트 마이크로페이먼트에 꼭 맞는 환경입니다.

에이전트는 라우터를 한 번 호출할 뿐입니다. 견적과 서명, 온체인 정산은 아래 레이어가 알아서 처리합니다.
